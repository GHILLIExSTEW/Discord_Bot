Playmaker Picks

Official play recording and results guide

📷Automatic image flow

1. Upload a betting-slip image in the configured image channel. 2. The bot reads selections, decimal/American odds, team, and units. 3. The bot posts User Reviewing Bet with a Review image button. 4. Review and confirm. 5. The bot records the play against the original image message and removes the review message. It does not repost the bet.

✍️Manual play entry

Use /play when there is no image. Enter units, number of legs, Leg 1 selection, Leg 1 odds, and the optional team. Additional legs are entered one at a time. Each leg and its odds are stored, then combined when the final leg is submitted.

🧪Testing without recording

Configure TEST_CHANNEL_ID, then use the protected command /testing enabled:true. Upload an image in the test channel. The bot parses the image without writing to the database, posting a bet, or requiring confirmation. Use Enter units if needed, then Complete test. Disable testing with /testing enabled:false.

Only configured operators or server managers can change the runtime testing toggle. A restart restores the default state.

✏️Editing a recorded bet

The tracking channel receives a Recorded Bet embed with an Edit bet button. Only the original user can edit it. The edit form loads each leg from the database, recalculates combined odds, and updates the stored play.

✅Results and reactions

The original user can react to the original bet message:

✅ Win   ❌ Loss   🅿️ Void   🌓 Partial

Win, loss, and void settle immediately. Partial sends a private follow-up for the remaining details.

📊Tracker updates

Use /update_tracker from any channel. It reads the original unit tracker tables, updates the existing Unit Summary message in RESULT_CHANNEL_ID, and sends only the separate Top Playmakers embed to TEAM_STATS_CHANNEL_ID.

🔧If something does not appear

Check that the bot is online, the user has the required role, the image channel is configured, and the bot can read messages, send messages, manage messages, and send direct messages. After deployment, pull the latest code and restart the systemd service.

Key settings: IMAGE_INPUT_CHANNEL_ID · TEST_CHANNEL_ID · TRACKING_CHANNEL_ID · RESULT_CHANNEL_ID · TEAM_STATS_CHANNEL_ID
